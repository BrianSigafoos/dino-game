# Dino Game

Dino Flip Facts is a one page flash card game with kid friendly dinosaur facts,
optimized for mobile.

## Quick start

- Run a local server from `docs/`:
  - `python3 -m http.server --directory docs 8000`
  - Visit `http://localhost:8000`

## GitHub Pages

- The site deploys from `docs/`.

## App files

- `docs/index.html`: UI markup.
- `docs/styles.css`: Styles and layout.
- `docs/app.js`: Flash card data and game logic.
